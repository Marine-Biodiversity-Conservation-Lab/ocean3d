# ocean3d: Three-Dimensional Marine Spatial Analysis

Facilitates the analysis of marine habitat in 3D, enabling descriptions
of habitat by depth and area. Provides tools for volume calculation,
environmental extraction, and spatial overlap analysis between species
ranges, fisheries, and depth-stratified environmental data.
