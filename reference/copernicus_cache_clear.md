# Clear the Copernicus cache

Remove all files downloaded to the default Copernicus cache.

## Usage

``` r
copernicus_cache_clear(confirm = TRUE)
```

## Arguments

- confirm:

  Logical. Require interactive confirmation. Default `TRUE`.

## Value

Invisibly, `TRUE` on success.

## Examples

``` r
if (FALSE) { # \dontrun{
copernicus_cache_clear()
} # }
```
